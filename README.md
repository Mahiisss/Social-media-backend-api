# 🚀 Social Media Backend API

A backend service for a social media platform supporting **posts, likes, follows, hashtags, personalized feeds, and user activity tracking**.

---

## ✨ Features

✅ Create, update, and delete posts  
✅ Like and unlike posts  
✅ Follow and unfollow users  
✅ Hashtag tagging and search  
✅ Personalized feed generation  
✅ User activity timeline  
✅ Pagination using `limit` and `offset`  
✅ Joi request validation  
✅ TypeORM migrations  
✅ PowerShell testing script for API coverage  

---

## 🛠 Tech Stack

- Node.js + Express  
- TypeScript  
- TypeORM  
- SQLite  
- Joi Validation  

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Mahiisss/Social-media-backend-api.git
cd Social-media-backend-api


Install dependencies:

npm install


Run database migrations:

npm run migration:run


Start the development server:

npm run dev


Server runs at:

http://localhost:3000
